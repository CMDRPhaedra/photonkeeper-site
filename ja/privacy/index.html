プライバシー

Photonkeeper はあなたに関する情報を一切収集しません。このページでは、それが具体的に何を意味するのか、そしてあなたが作ったデータが実際どこにあるのかを詳しく説明します。

← Photonkeeper に戻る

短く言うと。アナリティクス、テレメトリ、クラッシュレポート、広告、作成するアカウント、確認するライセンス、そしてあらゆる形の追跡 — いずれもありません。サードパーティ製 SDK はアプリ内に1つも入っていません。あなたが何をいつ撮影したかを知る人は、開発者を含めて誰もいません。あなたの画像があなたの管理下を離れることはありません。

運営者について

Photonkeeper は、英国の独立系開発者 Dale Forster が開発・公開しています。このページの内容に関するご質問は support@chryse.co.uk へどうぞ。実在の人間が読んでいる実在のアドレスです。

アプリが収集する情報

ありません。「少なめ」でも「匿名化・集計済み」でもなく、ゼロです。利用状況を報告するコードも、インストールごとの識別子も、初回起動時の通信も、あなたのデータをどこかへ送る仕組みも、このアプリには存在しません。

収集するものが何もない以上、売るものも、共有するものも、貸し出すものも、第三者に渡すものもなく、開示請求に応じて差し出せるものもありません。これは運用上の約束ではなく、アプリの作り方そのものから来る性質です。

アプリが行うネットワーク接続

以下が全リストです。入手経路によってわずかに異なります。

App Store 版

接続は1種類だけ。あなた自身のネットワーク上の、あなた自身の望遠鏡です。

  • USB 接続の場合、そもそもネットワーク接続ではありません。DWARF はディスクとしてマウントされ、アプリは他のボリュームと同じようにファイルを読み書きします。
  • Wi-Fi 接続の場合、アプリはあなたが入力したアドレスに対して、あなた自身のネットワーク上で FTP と HTTP を話します。送信専用です。アプリが着信接続を待ち受けることはなく、デバイスの探索やスキャンも行わず、この経路に関する情報が家の外へ出ることはありません。

App Store 版はこれ以外に、いかなる外部接続も行いません。後述のバージョン確認は、このビルドでは単に無効化されているのではなく、コンパイル時に取り除かれています。バイナリの中にアドレスすら含まれていません。

このサイトから直接配布している版

上記すべてに加えて、もう1つあります。直接ダウンロードされたアプリには、更新を届けるストアがないためです。

  • バージョン確認。アプリは1日1回、このウェブサイトに version.json（最新リリース名が書かれた小さなファイル）を要求し、自分自身と比較します。あなた、あなたのコンピュータ、あなたのアーカイブに関する情報は一切送信しません。この通信が明かすのは、あらゆるウェブリクエストが明かすもの — IP アドレスと、リクエストがあったという事実だけです。コードのダウンロードもインストールも行いません。新しいものがあればバナーを表示し、どうするかはあなたが決めます。設定 → アップデートを確認でオフにすれば、アプリはあなた自身の望遠鏡以外へ一切の外部接続を行いません。

Microsoft Store 版

接続の種類は App Store 版とまったく同じ1種類だけです。あなた自身のネットワーク上の、あなた自身の望遠鏡に対して、USB または Wi‑Fi で接続します。上に書いたとおりです。

バージョン確認は、このビルドには存在しません。オフにしているのでも、コンパイル時に取り除いているのでもなく、更新は Microsoft Store が扱うため、更新確認のコードがそもそも書かれていません。Windows 版は、あなた自身の望遠鏡以外へ、いかなる外部接続も行いません。

データの保存場所

あなたの Mac の中、しかも目に見える場所です。

  • アーカイブ — 撮影セッションそのもの。あなたが選んだフォルダの中の、Finder で開ける普通のディレクトリに入っています。セッションフォルダの名前が変わることはなく、中身が書き換えられることもありません。
  • セッションごとのマニフェスト — 各ファイルと SHA-256 チェックサムの一覧で、アーカイブ内の各セッションと並べて保存されます。検証とバイト単位で同一の書き戻しを可能にしているのがこれです。
  • カタログ — アーカイブの索引で、macOS では Application Support に、Windows ではローカルのアプリケーションデータに置かれます。派生データなので、削除してもマニフェストから再構築されます。
  • いくつかの小さな設定 — アーカイブの場所、アクセスを許可した望遠鏡、最後に使った Wi-Fi アドレス、外観の選択、バージョン確認を最後に実行した日時。
  • アクティビティログ — メモリ上にのみ保持され、アプリを終了すると消えます。

いずれもどこにも送信されません。このアプリにはクラウド機能も、同期サービスも、バックアップサービスもありません。アーカイブをバックアップしたい、NAS に置きたいという場合、それはあなた自身の管理下にあるあなた自身のストレージの話で、アプリはそこでも問題なく動きます。

アプリが触れられる範囲

App Store 版は macOS の App Sandbox 内で動作します。読み書きできるのは、あなたが選んだアーカイブフォルダと、開くパネルで明示的に許可した望遠鏡ボリュームだけで、ディスク上のそれ以外には触れません。この許可は記憶されるので繰り返し尋ねられることはなく、システム設定から取り消せます。

Windows 版は、その意味でのサンドボックスの中にはありません。パッケージ化された Windows デスクトップアプリは、あなた自身の権限で動作するため、原理的にはあなたが読めるものは読めてしまいます。実際に読み書きするのは2つだけです。あなたが選んだアーカイブフォルダと、あなたが接続した望遠鏡です。通常のデスクトップアプリとして動作する以上の特別な権限を Windows に要求することはなく、とくに広範なファイルシステムアクセスは要求しません。それは、1つのフォルダを使うためにマシン上の全ファイルへの許可を求めることになるからです。

どちらのプラットフォームでも、アプリは写真ライブラリ、連絡先、カレンダー、カメラ、マイク、位置情報、その他のシステムデータへのアクセスを一切要求しません。必要ないからです。

アプリの購入について

購入手続きは、購入したストアがすべて扱います。Apple のプライバシーポリシーのもとで Apple が、あるいは Microsoft のプライバシーに関する声明のもとで Microsoft が扱います。決済はそれぞれのシステム内で行われ、どちらもあなたの氏名・住所・支払い情報を開発者に渡すことはありません。開発者が受け取るのは、地域別の販売件数を集計した売上・財務レポートだけです。そこに個人を特定できる情報はなく、購入を特定の人物と結び付けたり、アプリがあなたのコンピュータ上で行う動作と結び付けたりする手段は存在しません。

メールをいただいた場合

そのメールにあなたが書いた内容を、こちらが持つことになります。用件が片付くまでのあいだ保持し、それ以上は保持しません。差出人をリストに追加することはありません。そもそもリストが存在しないからです。いただいた内容を他の誰かに渡すこともありません。

送る前に知っておくとよいこと。アクティビティペインのスクリーンショットは、これ以上ないほど有用なバグ報告です。ただしターゲット名やファイルパスが写り込むので、気になる場合は先に目を通してください。
