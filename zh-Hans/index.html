Photonkeeper

把 DWARF 3 或 DWARF Mini 上的拍摄记录，搬进你自己硬盘上一份像样的存档 — 再写回去时逐字节完全相同，望远镜照样能对它做叠加和重新叠加。

下载 macOS 版
版本 1.9 · 1.4 MB · macOS 14 或更高版本 · 已通过 Apple 公证
支持 DWARF 3 与 DWARF Mini。两者都用真实数据验证过：DWARF 3 由我本人测试，Mini 由一位机主完整跑过一遍来回流程。如果你的设备表现不对，或者哪里让你困惑，请告诉我：support@chryse.co.uk，欢迎附上截图。

它做什么

  • 把望远镜上所有新数据导入进来，并在复制的同时计算每个文件的 SHA-256 校验和，而不是复制完再单独跑一遍。
  • 把拍摄记录发送回望远镜 — 可按目标、日期、曝光或增益筛选 — 传出时计算哈希，写完后再读回确认。
  • 释放机身存储空间，但只针对那些刚刚与你的存档核对并校验通过的拍摄记录。
  • 把 M 42、M42 和 NGC 1976 归为同一个目标，而不是三个文件夹。
  • 日后可重新检查整个存档是否出现位腐，记住检查结果，并能从望远镜上重新取回损坏的文件。
  • 可以导入整张卡，也可以只导入你从列表里挑出的那几条拍摄记录。
  • 你要求时才从存档中删除拍摄记录 — 而且是移入废纸篓，绝不直接抹掉。
  • 每一项操作都可以先试运行，准确显示接下来会发生什么。

拍摄记录文件夹永远不会被改名，里面的内容也不会被改动 — 所有整理都发生在它们上层的目录里。

没有望远镜也能试

应用内置演示模式，带有示例数据和一份独立的示例存档，你可以先完整看一遍来回流程，再决定是否让它接触自己的拍摄数据。菜单：望远镜 → 试用演示模式。

安装

解压后把 Photonkeeper 拖入"应用程序"文件夹。首次打开时，macOS 会询问：

"Photonkeeper"是从互联网下载的应用。你确定要打开它吗？

点击打开。任何下载来的应用都会有这个常规提示 — Photonkeeper 使用 Apple Developer ID 签名并已通过 Apple 公证，所以你只需点一下，而不会看到 macOS 对未签名软件显示的拦截界面。

核对你下载到的文件

一个专职为你的数据算校验和的应用，理应也给出自己的校验和。对下载到的文件运行：

shasum -a 256 Photonkeeper-1.9.zip

cfc743443deb8802749e698f3afc36561db7c027e38c5102fac7828602c72792

系统要求

  • macOS 14 (Sonoma) 或更高版本，Apple 芯片或 Intel 均可。
  • 一台通过 USB 连接的 DWARF 3 或 DWARF Mini。
  • 一个存放存档的位置 — 外置硬盘也可以，而且即使你移动或重命名该文件夹，应用也会记住它。

隐私

Photonkeeper 不收集任何关于你的信息。没有分析统计，没有遥测，没有崩溃报告，不需要注册账户，不需要校验许可证，也没有任何形式的追踪，应用里根本不含任何第三方代码。包括我在内，没有人会知道你拍了什么、什么时候拍的。

你的存档、它的清单与校验和，以及少量设置项，全都留在你自己的 Mac 上。App Store 版本只发起一种网络连接 — 连到你自己网络上、你自己的望远镜。版本检查在该版本中于编译阶段就被完全移除。从本页下载的版本多了这一项检查，每天一次，并且可以关闭。

阅读完整隐私政策，其中逐条说明应用发起的每一个连接、你的数据究竟存放在哪里，以及你给我发邮件后会发生什么。
